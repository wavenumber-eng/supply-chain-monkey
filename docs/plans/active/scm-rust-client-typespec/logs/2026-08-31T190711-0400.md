# Log: rust-client-library core slice

Implemented the publishable async `scm-client` boundary for health, provider
status, search, detail, SPN, SPN batch, and bounded concurrent multi-provider
search. Provider-error envelopes are typed separately from sanitized
configuration, transport, HTTP, response-bound, and contract failure classes.
The client uses reqwest 0.13.4 with rustls, the platform verifier, and system
proxy support; redirects are disabled, authenticated remote HTTP is rejected,
loopback HTTP is explicit, bearer headers are sensitive, and base URL joining
preserves deployment prefixes.

Six in-process integration tests cover every supported operation, request
contracts, prefix/query/body encoding, token hygiene, redirect refusal,
timeouts, response bounds, cancellation and concurrency, explicit proxy
routing, default untrusted-certificate rejection, and explicit private-root
acceptance. Locked workspace format, generation freshness, check, Clippy,
tests, doctests, rustdoc, and pinned Rust repo/language audit pass. A combined
locked Cargo package invocation stages the contracts candidate in a temporary
registry and verifies both public crates successfully. The slice is ready for
independent review; cross-platform CI execution remains part of release
signoff.
