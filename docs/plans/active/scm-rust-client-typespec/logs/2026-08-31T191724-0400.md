# Log: scm-cli-proof

Implemented the `scm` binary over the public `scm-client` crate for health,
providers, search, detail, SPN, and SPN batch. The CLI accepts the service URL
by `--url` or `SCM_URL`, reads authenticated credentials only from `SCM_TOKEN`,
has no token argument or credential-file behavior, supports an explicit
private CA bundle, and applies timeout, response-size, and concurrency bounds.
Stable human summaries and complete `--json` envelopes are available;
provider-error envelopes exit with code 2 while client failures exit with 1.

Three subprocess/in-process-server tests exercise all commands, sorted human
output, typed JSON, batch bodies, provider-error exit behavior, missing-token
handling, and credential absence from argv, URLs, stdout, and stderr. Locked
workspace format, generation, check, Clippy, tests, doctests, rustdoc, and Rust
policy audit pass. A combined locked Cargo package command verifies contracts,
client, and CLI candidates in dependency order. The slice is committed for
independent review before status closure.
