# Log: python-contract-cutover

FastAPI health, provider-status, search, detail, SPN, and SPN-batch routes now
declare generated endpoint request and response roots re-exported only through
`scm.models`. A shared server response boundary projects existing provider
models into those roots and validates encoded JSON against the unmodified
TypeSpec-generated schema. The deprecated SSE surface applies the same checked
SearchEnvelope and StreamDoneEvent encoding without changing its compatibility
authentication boundary.

The source-compatible Python SCMClient now streams and bounds response bytes,
strict-decodes each endpoint through the shared contract codec, and projects
generated envelopes back to the supported ServiceEnvelope return type. SPN
batch requests are generated-model/schema encoded. A deterministic native-model
projection corrects datamodel-code-generator's nullable rendering of the
optional but non-nullable include_raw boolean and is documented in ADR 0013.

New executable proofs cover public re-exports, served OpenAPI roots, live route
schema conformance, explicit-null rejection, strict duplicate-member rejection,
response-size enforcement, and generated batch request encoding. The Python
sdist explicitly excludes the Rust target tree so the existing package signoff
remains bounded in the polyglot workspace. Fresh results: 122 passed and 22
opt-in tests skipped; Ruff, Pyright, contract/vector freshness, and Python-model
freshness pass. The slice remains active pending independent review.
