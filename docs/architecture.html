Architecture

Supply Chain Monkey centralizes electronic component supplier access behind a FastAPI service and exposes shared Pydantic contracts plus a small Python HTTP client.

Boundaries

  • src/py/scm/models.py owns public response contracts.
  • src/py/scm/client.py owns consumer HTTP access.
  • src/py/scm/server/ owns the FastAPI app and providers.
  • tests/L0_foundation/ owns fast contract coverage.
  • tests/L99_signoff/ owns release and deployment gates.

Deployment Boundary

Runtime credentials are environment variables owned by the deployment host. Provider modules must not load local files or mutate environment state at import time.
