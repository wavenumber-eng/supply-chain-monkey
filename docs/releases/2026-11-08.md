# Supply Chain Monkey Release Candidate: 2026-11-08

## `2026.11.8`

This candidate bumps the Python `supply-chain-monkey` package to `2026.11.8`.
The import package and Rust CLI remain `scm`. The unpublished Rust crates stay
at `0.1.0`; consumers should pin the reviewed release commit.

- Add read-only JLC My Parts Lib inventory listing and exact C-code/MPN lookup
  through the existing SCM bearer token, Python and Rust clients, and CLI.
- Preserve the four JLC source balances separately. An incomplete bounded scan
  returns an error rather than a partial or falsely empty result.
- Add the opt-in Rust serde JSON arbitrary-precision bridge used by ALX.
- Carry forward the emSign CA trust remediation from the production baseline.

Production publication and tag creation remain pending integration through
`dev` and the release gates.
